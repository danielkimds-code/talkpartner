# TalkPartner

아이패드용 영어·베트남어 말하기 연습 앱.

- 주소: https://danielkimds-code.github.io/talkpartner/
- 영어 코스: 8개 단원 54개 레슨(클레임 대응 14 · 고객 감사 6 · 공정·데이터 6 · 납기·생산 5 · 회의·전화 6 · 협력사·현지 직원 4 · 출장 7 · 사교 6). 레슨마다 문법 표현 → 대화문 듣기 → 따라 말하기 → 퀴즈 → 대본 리허설 → 실전 대화
- AI 시나리오: 단원마다 원하는 상황을 적으면 AI가 같은 형식의 새 레슨을 만들어 계정에 저장
- AI 즉시 피드백: 대본과 다르게 말해도 AI가 의미를 판단해 바로 고쳐 주고, 리허설 상대역은 즉흥으로 받아 줌
- 자유 대화: 배운 표현을 AI가 알고 활용하도록 유도 → 교정 노트(고쳐 말하기·문장 틀·모범 대본·배운 표현 활용 체크)
- 베트남어: 왕초보 기초 코스(단어 8개 레슨 → 짧은 문장 5개 레슨). 듣기 → 따라 하기 → 뜻 고르기 → 말하기
- 복습: 1·3·7·14·30일 간격 반복 카드, 문장 틀 드릴, 대본 리허설
- PDF: 교정 노트·레슨 학습지를 굿노트로 보내기
- 저장: Cloudflare Worker(talkpartner-relay) KV 클라우드 + 기기 캐시. 로그인 계정마다 진도·복습 카드·노트를 따로 저장

파일: `index.html`(앱·대화), `study.js`(노트·복습·리허설·코스·PDF), `en-course.js`(영어 코스 데이터), `vi-course.js`(베트남어 코스 데이터), `worker.js`(중계 서버 템플릿 — 키는 비어 있음)
