연결됨

중계 서버 주소 · aiapiflow는 웹페이지에서 바로 연결할 수 없어서 Cloudflare 중계 서버를 거칩니다.

중계 서버 만드는 법 (처음 한 번, 약 5분)
  1. 중계 코드 복사:
  2. dash.cloudflare.com에서 무료 가입 후 로그인
  3. 왼쪽 메뉴 Workers & Pages (또는 Compute → Workers) → Create → Start with Hello World!
  4. 이름에 talkpartner-relay 입력 → Deploy
  5. Edit code → 원래 코드를 모두 지우고 복사한 코드를 붙여넣기 → 오른쪽 위 Deploy
  6. 화면에 나오는 주소(https://talkpartner-relay.○○○.workers.dev)를 복사해서 위 칸에 붙여넣고 저장하고 연결 확인
